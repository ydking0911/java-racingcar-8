# java-racingcar-precourse

## 구현할 기능 목록

### 1. 자동차 관리
- 자동차 이름 입력 및 검증 (5자 이하, 쉼표로 구분)
- 자동차 전진/정지 로직 (랜덤값 4 이상일 때 전진)
- 자동차 위치 추적

### 2. 게임 진행
- 이동 횟수 입력 및 검증
- 각 라운드별 자동차 상태 출력
- 게임 결과 출력

### 3. 우승자 결정
- 최종 위치가 가장 높은 자동차 찾기
- 공동 우승자 처리 (쉼표로 구분하여 출력)

### 4. 예외 처리
- 잘못된 입력값에 대한 IllegalArgumentException 발생
- 애플리케이션 종료 처리

## 게임 규칙
- 각 자동차는 0~9 사이의 랜덤값이 4 이상일 때 전진
- 자동차 이름은 5자 이하로 제한
- 이동 횟수는 사용자가 입력
